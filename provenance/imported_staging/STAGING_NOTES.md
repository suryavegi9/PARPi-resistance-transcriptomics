# Initial repository import — review required

This package contains 53 numbered top-level script copies plus the shorter D1 script variant, five exact frozen synthesis inputs, original final synthesis output files, selected sample metadata and two nonempty session records. All staged scientific outputs are byte-identical to the supplied source archive. The only intended script modification is replacement of each workstation-specific `setwd` invocation with `setwd(Sys.getenv("PARPI_PROJECT_ROOT", unset = getwd()))`; run from the repository root or specify the environment variable. Script execution was NOT tested. Original versions remain in the supplied archive; see STAGING_MANIFEST.csv for original and staged SHA-256 digests.

This is not the final publication package. Do not execute all scripts in numeric order: some are historical or exploratory, and D1 script variants differ. Missing script numbers and upstream dependencies need review. The six-accession master remains solely a frozen dependency of final integration. The original Figure 8 artwork retains its old numbering and overlap and is not submission artwork. The final publication-build supplementary S1–S3 are not included. Raw inputs, gene-level result bulk, old manuscript tables, temporary R files, nested ZIPs, and redundant exports are deliberately excluded. Historical environment records are incomplete. No biological analyses were rerun.

Credential and common absolute-path pattern scans of selected text files found no matches; this is not exhaustive security or licensing review. Keep the repository private until the author approves release.
