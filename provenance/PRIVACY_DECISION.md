# Author decision required before public release
The initial 45 commits contain a personal email address in author/committer metadata. Its value is deliberately not reproduced here. Future commits use the verified GitHub no-reply identity. Changing future settings does not remove historical exposure.

Choose explicitly before publication:
1. Approve publishing the existing repository with the historical email visible.
2. Request a separate clean-history release repository, retaining this historical repository privately.

Neither choice has been assumed. No remote history was rewritten, no force push performed, and no repository identity changed. This is the remaining privacy approval gate, even if technical checks pass. Exact private originals containing workstation paths stay outside the release tree. The redundant staging archive is retained privately and removed from the current release tree; it remains reachable in historical commits.
