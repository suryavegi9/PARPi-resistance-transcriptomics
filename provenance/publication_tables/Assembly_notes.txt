S1 joins the frozen D1–D6 master to the saved D7A/D7B and D8 Hallmark outputs. D1–D6 formal votes are copied unchanged; D7/D8 contribution rules follow script 63. Final counts and classifications match every pathway in Figure8_accession_source_table.csv.

Final counts and classifications match every pathway in Figure8_model_level_source_table.csv. HCC1806 H1/H2 are contrasts within one cellular model, not independent biological models or studies.

S3 preserves script 63's ON/OFF values and all numeric fields in Figure8_treatment_state_source_table.csv. The five-category hierarchy follows historical script 47. The strict D7-aware separation rule is recorded in the recovered conversation (6b044467-bbf4-83ee-b71d-4c324435c209, publication-assembly turn): D7 must be concordant and all three ON values must separate from all three OFF values. Script 63 alone does not contain this five-category rule. The resulting categories reproduce both the locked counts and the named pathways in the recovered checkpoint. This new publication table is explicitly an assembly of frozen outputs, not an original saved D1–D8 classification file.

Missing D7 NES is represented as NA for model discordance. It is not replaced by zero. Formal direction code zero means no vote. No composite accession P values have been invented. The CSVs and workbook preserve all 50 pathways.
